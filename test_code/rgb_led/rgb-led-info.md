## rgb led test code
This is only for testing or getting starded this is not the actual program!
1. flash `test_code/rgb_led/rgb.ino` onto you arduino and make sure the wiring is correct
2. You can set your own rgb color (see color picker for difrend colors https://share.google/LpXywytx3atGxhD3B) 

|  PIN | Arduino pin |
| --- | --- |
| RGB red pin | D4 |
| RGB green pin | D5 |
| RGB blue pin | D6 |
| RGB gnd pin | GND |

You can choose your own pins just make sure to update the variables at the top, and ensure that the pins support PWM you can identify this by the small ~ symbol.
